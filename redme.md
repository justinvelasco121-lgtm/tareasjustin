# Cálculo de Costo de Proyecto

**Estudiante:** Justin Issac Velasco Jama

## Descripción del problema resuelto
Este proyecto contiene un script en Python que resuelve un problema práctico de cotización: calcular el costo total de un proyecto de desarrollo de software. 

Se implementó una función que recibe dos parámetros (las horas de desarrollo estimadas y la tarifa de cobro por hora). El algoritmo procesa estos valores, realiza la multiplicación correspondiente y retorna el costo total, mostrando el resultado final en la consola.
